# Start here

1. Open Terminal and run:
   ```
   cd ~/ghost-line-kit
   claude
   ```
2. In Claude Code, type: `/setup`
   It reads CLAUDE.md, builds the repo skeleton and CI, and asks before creating the public GitHub repo.
3. Open `~/ghost-line-kit` in the **Kiro IDE** and paste **Spec 1** from `docs/KICKOFF.md` (Part 3) in spec mode.
4. Any time you're unsure what's next, run `/status` in Claude Code.

Your own jobs today: request Kiro credits on Devpost, and create the Africa's Talking sandbox account.
